# מִלִּים · Psychometry-Words

מאמן אוצר מילים נגיש, מגוון (gamified) וידידותי לקשב ולריכוז ללימוד מילים גבוהות בעברית לקראת הבחינה הפסיכומטרית, עם 206 מילים מטוהרות מהמאגר (רק ערכים ברמת רישום גבוהה, לא מילים נפוצות) ומנוע חזרה מרווחת (SM-2).

## הפעלה

```bash
npm install
npm run dev            # שרת פיתוח
npm run build           # build לפרודקשן ל-dist/
npm run test             # בדיקות יחידה (Vitest)
npm run validate-words   # בדיקת תקינות מבנה מאגר המילים
npm run check-contrast   # בדיקת ניגודיות WCAG AA לערכת הצבע
```

## מה יש כאן

- **בית** — לוח מחוונים: רצף ימים, רמה נוכחית עם טבעת התקדמות, סיכום מילים מוטמעות וכוכבים, וקיצורים ללמידה/תרגול מהיר (5 שאלות).
- **למידה** — כרטיסיות פנים־אחור עם ניקוד, הגדרה, דוגמה, נרדפים והפכים, בקבוצות (מקבצים) קצרות של 5 מילים עם מסך חגיגה בסיום כל מקבץ — מותאם ללמידה בקטעים קצרים ולריכוז מוגבל.
- **תרגול** — חמישה סוגי שאלות (מילה←הגדרה, הגדרה←מילה, נרדף/הפך, השלמת משפט, הקלדה) עם מסיחים "קרובים" מאותה רמת קושי, משוב מיידי ולא־מעניש על תשובות שגויות, ומסך "כל הכבוד!" עם כוכבים בסיום כל מקבץ.
- **הישגים** — סך כוכבים, רמה (מתחיל → חוקר → בקיא → מומחה → אלוף) עם סולם רמות, ותגים לפי אבני דרך אמיתיות (כוכב ראשון, רצף שבוע, מילים מוטמעות ועוד).
- **הגדרות** — גודל טקסט, גופן קריא יותר (ידידותי לדיסלקציה), סינון לפי רמה/תגית, כיוונון מלא של פרמטרי ה-SM-2, ומצב מפתח. ניהול הנתונים (חיפוש, ייבוא/ייצוא CSV/JSON, קונסולת שאילתות, בדיקת תקינות) נגיש דרך כפתור "ניהול מילים ונתונים" בהגדרות, ולא כלשונית ראשית — כדי לצמצם החלטות במסך הבית.

כל ההתקדמות, הרצף וההגדרות נשמרים ב-`localStorage` בדפדפן בלבד — אין שרת ואין שליחת נתונים החוצה.

**תזכורות לטלפון** נשקלו ונדחו במכוון בשלב הזה: התראות אמיתיות שמגיעות גם כשהאפליקציה סגורה (בעיקר ב-iOS) דורשות שרת push קטן (VAPID + מתזמן), שהוא הרחבה אמיתית מעבר לאתר סטטי — אפשר להוסיף בהמשך כפרויקט נפרד.

## עיצוב וגיימיפיקציה

האפליקציה משתמשת בפלטת צבעים יחידה וקוהרנטית ("בריינית" — סגול/מנטה/ורוד/זהב) בהשראת אפליקציות למידה מגוונות (gamified), במקום חמש ערכות פסטל נפרדות שהיו בגרסה הקודמת. כל צבע בפלטה משמש לתפקיד קבוע (ראשי/הצלחה/התראה/תגמול), לא צבעים אקראיים. הקוביה (`Mascot`) היא איור SVG גיאומטרי פשוט, ולא איור מלוטש — ניתן להחליף בעתיד אם רוצים רמת גימור גבוהה יותר.

## פריסה ל-GitHub Pages

הפרויקט מוגדר לרוץ תחת נתיב `/Psychometry-Words/` (`base` ב-`vite.config.ts`) ויש workflow מוכן ב-`.github/workflows/deploy.yml` שבונה ופורס אוטומטית בכל push ל-`main`, וגם ניתן להפעלה ידנית מלשונית Actions (`workflow_dispatch`).

כדי להפעיל בפעם הראשונה:
1. למזג את השינויים ל-`main` (ה-workflow רץ על push ל-branch הזה).
2. ב-repo settings: **Settings → Pages → Source → GitHub Actions**.
3. לאחר ה-push הראשון ל-`main`, ה-workflow ירוץ אוטומטית והאתר יעלה לכתובת `https://aloneden0-byte.github.io/Psychometry-Words/`.

אם רוצים לבדוק build עם ה-base path מקומית לפני הפריסה: `npm run build && npm run preview`.

## נגישות

הפרויקט נבנה עם דגש על נגישות, כולל שיקולים ידידותיים לקשב וריכוז (ADHD): מקבצי למידה קצרים (5 יחידות), משוב מיידי ולא־מעניש, יעדי מגע גדולים (מינימום 52px בכפתורי תשובה), ללא טיימרים מלחיצים, וניווט צפוי וקבוע (מסכי חגיגה תמיד חוזרים ל"בית"). בנוסף: ניווט מלא במקלדת (כולל מקשי קיצור למספרים בשאלות ולציוני הזכירה בלימוד), `skip link`, אזורי `aria-live` לעדכוני מצב, תבנית ARIA תקנית ללשוניות, מלכודת פוקוס בחלון העריכה, וטבעת מיקוד בניגודיות גבוהה (ולא בצבע הפסטל של הערכה, שנכשל במבחן WCAG). ערכת הצבע היחידה נבדקה מול WCAG AA (יחס ניגודיות 4.5:1 לטקסט, 3:1 לרכיבים לא-טקסטואליים) באמצעות `npm run check-contrast`. קיים `tests/e2e/smoke.spec.ts` שמריץ סריקת נגישות אוטומטית (axe) על כל לשונית, על מסך הנתונים ועל מסך החגיגה.

## מגבלה חשובה — דיוק לשוני

206 המילים במאגר (75 מהמערכת המקורית + מילים שנוספו במאגרי `src/data/batches/` ועברו סינון להסרת מילים נפוצות) נכתבו ואומתו מבחינה מבנית (`npm run validate-words` בודק שדות חסרים, כפילויות, ורמות לא חוקיות), אבל **הניקוד והשורש של הערכים החדשים לא עברו בדיקה על ידי דובר עברית מקצועי או מקור מילוני**. לפני שימוש לצורכי הוראה או הפצה רחבה, מומלץ לעבור על הערכים (בייחוד ניקוד ושורש) מול מילון סמכותי (כגון אתר האקדמיה ללשון העברית או רב־מילים) — לשונית "בדיקת תקינות" בנתונים תופסת רק בעיות מבניות, לא טעויות ניקוד עדינות.
